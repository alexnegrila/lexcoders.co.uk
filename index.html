How I work

  • Spec first. OpenAPI contracts and architecture decision records come before code. Agents implement against them, not against a prompt.
  • Guardrails by structure. An agent skill for each delivery step, read-only reviewers, test-first implementers, and gates every change has to pass.
  • Measured, not assumed. Review accuracy measured every week, alongside cycle time and fix times, so the team knows whether the AI is helping.

AI code review the team trusts

Platform team, 2025–26

Built the team's AI review skill from its own pull-request comments, commit history and terminology, and tuned it every week on how its comments landed. The share of its comments that applied to the code rose from 40% with the default model to 80%, and review throughput rose by 30%.
